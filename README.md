# Modelo predictivo de regresión lineal

Este proyecto aplica un modelo de **regresión lineal múltiple** para predecir el precio de venta (`sales_price`)
en función de variables como el costo de producción y el tamaño del producto.

##  Archivos del repositorio
- `Modelo predictivo regresión Lineal.ipynb`: Notebook principal con el análisis, visualizaciones y resultados del modelo.
- `interview_data.csv`: Dataset utilizado para entrenar y evaluar el modelo.
